# LunaRoute build dependencies

Public mirrors of unmodified, checksum-pinned upstream build archives whose original download locations are not durable. This repository contains no application source, credentials, or customer content.

## FFmpeg

[FFmpeg n8.1.3-25-g611cec792a](https://github.com/lunaroute/build-dependencies/releases/tag/ffmpeg-n8.1.3-25-g611cec792a) preserves the original BtbN linux64 GPL 8.1 archive byte-for-byte. The release records its SHA256, original source/build provenance, and GPL v3 license. Verify the downloaded archive against its `SHA256SUMS` before extraction.

Each artifact retains its original upstream license and copyrights; this repository does not relicense the artifacts. Source and build/dependency recipes are linked in the release notes.

Published dependency assets must not be replaced, retagged, or automatically expired. New bytes require a new release and an explicit downstream checksum update. There are no artifact-pruning workflows.
